# Benchmark results
These folders contain results from three different runs of the benchmark. We have three incase of a need to write errorbars.

The CSV files are rendered from tensorboards generated by the client. However, these consume multiple GBs. Can be sent upon request. The tensorboards also has additional data like CPU usage, etc.

15th of April (`./plot_data_15thApril`) is used in the first edition of the paper.

16th of April run seems to have one "offset" - Pytorch "inferenceonly" for 8 gpus has a lower performance than with IO - this doesn't make sense. My guess is that another process used computational resources, such as anti-virus checks, etc.
